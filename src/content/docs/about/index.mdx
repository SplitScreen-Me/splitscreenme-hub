[SplitScreen.Me](https://github.com/SplitScreen-Me) is a community of players and developers who want every PC game
with multiplayer to be playable on one screen. It gathers the open-source split-screen projects for PC under one
roof, and it's run by volunteers.

## The projects

### Nucleus Co-op

The app most people know: a free, open-source Windows tool that runs several copies of a game, gives each one its
own controller, keyboard or mouse, connects them and tiles the windows. Its goal is to make local co-op on one PC
as easy as on a console. [Get started](/doc/getting-started) or browse the
[source code](https://github.com/SplitScreen-Me/splitscreenme-nucleus).

### The hub

The catalogue of community handlers, with a page for every game: how many players, which inputs, the author's
notes, versions and comments. It's this site's [hub](/hub), and the **Get games** screen inside Nucleus Co-op reads
it through the [public API](/doc/api).

### Proto Input

The set of libraries Nucleus Co-op injects into games to give each copy its own keyboard, mouse and controller, and
to fake window focus. Written by [Ilyaki](https://github.com/Ilyaki), it can also be used on its own, without
Nucleus. [How it works](/doc/handlers/proto-input).

### Universal Split Screen

[Universal Split Screen](https://universalsplitscreen.github.io/), also by Ilyaki, is a standalone app that routes
Windows input to several game windows. Proto Input superseded it inside Nucleus Co-op, but it remains handy on its
own.

## Who's behind it

Nucleus Co-op was created by [Lucas Assis](https://github.com/lucasassislar). [ZeroFox](https://github.com/ZeroFox5866)
took it further with the Alpha 8 Mod, [Ilyaki](https://github.com/Ilyaki) brought multiple keyboards and mice,
Proto Input and better hooks, and [Mikou27](https://github.com/Mikou27) led the 2.x versions. [r-mach](https://github.com/r-mach)
built the website, the hub, the handler API and the Nucleus Co-op 3 interface. Handler authors such as Talos91,
PoundlandBacon, Pizzo and maxine64, along with the SplitScreenDreams Discord community, made hundreds of games
playable and keep testing them. The [history](/doc/about/history) tells how it all came together.
