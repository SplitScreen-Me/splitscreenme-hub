Work through these in order: the first three sections fix almost every case.

## Install the runtimes

Nucleus Co-op needs the
[.NET Framework 4.7.2](https://dotnet.microsoft.com/en-us/download/dotnet-framework/net472) or later, the
Visual C++ 2015-2022 Redistributable in **both** [x86](https://aka.ms/vs/17/release/vc_redist.x86.exe) and
[x64](https://aka.ms/vs/17/release/vc_redist.x64.exe), and the
[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/). Nucleus offers
to install the last two on first start; if you declined, install them now, then restart your PC.

On Windows 11, also install the
[DirectX End-User Runtime](https://www.microsoft.com/en-us/download/details.aspx?id=35) if you haven't.

## Files go missing

An antivirus that flags some Nucleus Co-op files (input hooks, network emulators) may delete them without
asking. An error such as **"ProtoInputHooks64.dll is missing from your Nucleus Co-op installation folder"** is the
classic sign. These detections are false positives.

1. Add the Nucleus Co-op folder to the
   [Microsoft Defender exclusions](https://support.microsoft.com/en-us/windows/add-an-exclusion-to-windows-security-811816c0-4dfd-af4a-47e4-c301afe13b26),
   or your antivirus' equivalent.
2. Extract the release again into that folder, so the missing files come back.

## Extract it properly, in the right place

- **Unblock the zip** before extracting: right-click, **Properties**, tick **Unblock**.
- **Extract with [7-Zip](https://www.7-zip.org/)**, into a new, empty folder. Don't extract over an older version.
- **Use a folder at the root of a drive**, such as `C:\NucleusCo-op`: not in `Program Files`, not in OneDrive,
  your Desktop, Documents or Downloads.

## A blank or white window

The interface of Nucleus Co-op 3 is drawn by Microsoft Edge WebView2. If the window opens but stays empty,
install or repair the
[WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/) (the Evergreen version), then
start Nucleus Co-op again.

## Windows blocks it

- **"Windows protected your PC"** (SmartScreen): choose **More info**, then **Run anyway**.
- **Controlled folder access** (ransomware protection in Windows Security) can stop Nucleus Co-op from writing
  to its folder: allow `NucleusCoop.exe` in it, or keep the folder out of protected locations.

## Still nothing

- **Restart your PC.** Leftover game copies or helpers from a crashed session can block a new start.
- **Run it as administrator once**: right-click `NucleusCoop.exe`, **Run as administrator**. If that works, the
  folder's permissions are the problem: move Nucleus Co-op to `C:\NucleusCo-op`.
- **Try a clean copy**: extract the latest release into a brand new folder and start it from there.

If it still doesn't open, ask on [Discord](https://discord.com/invite/QDUt8HpCvr) or
[report a bug](/doc/troubleshooting/report-a-bug) with your Windows version and any error message (a screenshot
helps).
